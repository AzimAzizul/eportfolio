ShopLite

What it is

An e-commerce platform with an AI shopping assistant. When a shopper stalls at checkout, the chatbot steps in to answer questions and help close the sale.

My role

Front-end developer and builder of the AI chatbot, in a team of 4.

Built with

Java 21Spring BootPostgreSQLGoogle GeminiHTML/CSS/JSDocker

Status

Live on Render. The free server sleeps when idle, so the first load can take up to a minute.

Limitations

The chatbot runs on the free tier of Gemini (gemini-3.5-flash-lite). When the daily quota runs out it may stop replying, and it has not been tuned for this store's product scope yet.

MasakGram Prompt

What it is

A client–server tool that sends Malay cooking-video transcripts to local LLMs and compares prompt techniques (zero-shot, few-shot, chain-of-thought, structured output) against ground truth, flagging hallucinations.

My role

Integrated the Java application with local LLMs via LangChain4j and Ollama, and ran quality checks to make sure the project met its requirements. Group of 5.

Built with

JavaLangChain4jOllamaMySQLSwingSockets

Status

Desktop app that runs local AI models, so there is no web demo. Screenshots show it running.
